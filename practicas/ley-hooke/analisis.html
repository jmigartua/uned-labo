Mechanics Practice 2: Hooke’s Law

Physics Lab (1st Course)

2026-10-29

Objective

Use two experimental procedures with the same vertical spring setup:

  • static elongation to calibrate the spring constant,
  • and oscillation periods to obtain the spring constant again by linearization,

then compare both values and estimate the local gravitational acceleration.

Instrument Precisions

  • Elongation reading on the vertical scale: 1 mm = 0.001 m
  • Chronometer precision for 20T: 0.01 s
  • Mass values are treated as nominal values with negligible uncertainty compared with the reading uncertainties above.

Static Calibration

For the static dataset, Hooke’s law is modeled as

P = K \, \Delta x + P_0

where:

  • K is the spring constant,
  • P_0 is the intercept of the experimental fit.

Static calibration fit-only results (1\sigma):

  • K_{\mathrm{static}} = (16.1698 \pm 0.2286)\ \mathrm{N\,m^{-1}}
  • P_0 = (-0.01910 \pm 0.01525)\ \mathrm{N}
  • R^2 = 0.996812

Plot 1: Static Calibration P vs \Delta x

Dynamic Method

For small oscillations of a mass-spring system with effective oscillating mass (\alpha m):

T^2 = \frac{4\pi^2}{K} \, M + \frac{4\pi^2}{K} (\alpha m)

This is a linear model:

y = a x + b

with:

  • y = T^2
  • x = M
  • a = \dfrac{4\pi^2}{K}
  • b = \dfrac{4\pi^2}{K}(\alpha m)

Dynamic fit-only results (1\sigma):

  • a = (2.371016 \pm 0.080864)\ \mathrm{s^2\,kg^{-1}}
  • b = (0.054185 \pm 0.008852)\ \mathrm{s^2}
  • K_{\mathrm{dynamic}} = (16.6504 \pm 0.5679)\ \mathrm{N\,m^{-1}}
  • (\alpha m) = (0.022853 \pm 0.004437)\ \mathrm{kg}
  • R^2 = 0.988502

Plot 2: Linearized Dynamic Problem T^2 vs M

Local Gravity as a Derived Quantity

From the static fit

\Delta x = s\,M + \Delta x_0

and the relation

\Delta x = \frac{g}{K} M + \Delta x_0

we identify:

g = K_{\mathrm{dynamic}} \, s

Derived fit-only local gravity (1\sigma):

  • s = (0.605470 \pm 0.008273)\ \mathrm{m\,kg^{-1}}
  • g_{\mathrm{local}} = (10.0813 \pm 0.3704)\ \mathrm{m\,s^{-2}}

Second Round: Instrument-Precision Propagation

The reported fit-only uncertainties above come from the regression covariance matrices. Now we add instrument contributions:

  • elongation reading: \pm 0.001\ \mathrm{m}
  • timing of 20T: \pm 0.01\ \mathrm{s}

Both are modeled as rectangular distributions and propagated by Monte Carlo.

Global results (fit + instrument, 1\sigma):

  • K_{\mathrm{static}} = (16.1698 \pm 0.2391)\ \mathrm{N\,m^{-1}}
  • K_{\mathrm{dynamic}} = (16.6504 \pm 0.5680)\ \mathrm{N\,m^{-1}}
  • K_{\mathrm{direct}} = (15.9216 \pm 0.3502)\ \mathrm{N\,m^{-1}}
  • (\alpha m) = (0.022853 \pm 0.004438)\ \mathrm{kg}
  • g_{\mathrm{local}} = (10.0813 \pm 0.3730)\ \mathrm{m\,s^{-2}}

Discussion: Compatibility of the Three Spring-Constant Estimates

The three values compared in the discussion are:

  • static calibration from the fit of P vs \Delta x,
  • direct estimate from the mean of the pointwise ratios P_i/\Delta x_i,
  • dynamic estimate from the fit of T^2 vs M.

Notes

Summary

  • The spring constant is obtained independently by a static calibration and a dynamic linearized fit.
  • The direct pointwise estimate K_i = P_i / \Delta x_i is included as a third comparison value for the discussion.
  • The local value of gravity is derived from the dynamic K and the static slope \Delta x vs M.

Theory and Calculations

For the static calibration:

P = K \, \Delta x + P_0

For the dynamic method:

T^2 = \frac{4 \pi^2}{K} \, M + \frac{4 \pi^2}{K} (\alpha m)

with the mathematical identification:

y = a x + b

so that:

K = \frac{4 \pi^2}{a}

and

(\alpha m) = \frac{b}{a}

Uncertainty transfer from the slope:

\Delta K = \left| 4 \pi^2 \frac{-1}{a^2} \right| \Delta a

For (\alpha m)=b/a, the propagation rule is:

\Delta (\alpha m) = \sqrt{ \left(\frac{\partial (\alpha m)}{\partial b}\right)^2 (\Delta b)^2 + \left(\frac{\partial (\alpha m)}{\partial a}\right)^2 (\Delta a)^2 }

with:

\frac{\partial (\alpha m)}{\partial b} = \frac{1}{a}, \qquad \frac{\partial (\alpha m)}{\partial a} = -\frac{b}{a^2}

In the code, the covariance between a and b from the regression is also included, which is the more rigorous treatment.

The local gravity is obtained from the auxiliary static fit:

\Delta x = s M + \Delta x_0, \qquad g = K_{\mathrm{dynamic}} s

where:

s = \frac{g}{K}
